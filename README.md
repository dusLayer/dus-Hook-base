# dus Hook Base
## A Unity hook base for IL2CPP/Mono games. using MinHook, RetSpoof, and a fancy animated snowflake menu.

# Features
## IL2CPP & Mono – Supports both Unity runtimes

## MinHook – Reliable API hooking

## RetSpoof – Return address spoofing for stability

## Animated Menu – Modern GUI with falling snowflakes

## Easy to extend – Quickly add your own hooks

# Build
## Open the project in Visual Studio

## Select x86/x64 depending on the target game

## Build → dus Hook Base.dll

# Injection
## Inject the DLL into the Unity game using any injector.
## The menu appears automatically (open/close with DELETE by default).
